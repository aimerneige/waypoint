# 界面打磨待办（M5 统一处理）

架构师在各里程碑验收截图中发现、但不阻塞功能的问题。M5 必须逐条处理并在回复中标注结果。

## 来自 M2 验收
- 账目列表日期分组标题显示原始 ISO（"2026-11-10"），应使用 `domain/format.ts`（"11月10日 周二"）。
- 账本首页 4 个筛选下拉占据半屏：改为一个"筛选"按钮 + 已选条件 chip，筛选面板放 ResponsiveOverlay。
- 人民币支付账目的状态徽标显示"手动"，语义不对：cny 方式不显示汇率状态徽标（或显示"人民币"）。
- 心愿卡片状态徽标"已安排（第 2 天）"换行成两行：徽标不换行，过长时缩写为"第 2 天"。
- 结算页"每人明细"使用 `<details>` 原生三角，与整体风格不一致：改为可展开的列表卡片（ListCard + Chevron）。
- 记账表单的"币种"为整宽居中按钮，可与金额并排（金额输入右侧的币种选择按钮）。

## 来自 M3 验收（高优先级）
- **行李列表过于冗长**：每件物品占 3 行（名称 / "每人一份" / 分类），12 件物品占满数屏。改为单行行项（≥48px）：左侧大号自定义复选框（整行可点，44×44 触摸区）、名称、右侧（公共物品）负责人头像 + ⋯ 菜单；分类作为分组标题而非每行重复；"每人一份 / 仅我需要带"只在需要时用小图标表示；去掉与复选框重复的"已装/待装"徽标。已装项可折叠到"已装（N）"分组。
- 出发提醒横幅文字被"今天不再提示"按钮遮挡：横幅文字换行、按钮放第二行或改为关闭图标。
- 投票截止时间显示"2026/11/9 03:29:00"：统一走 `domain/format.ts`（"11月9日 03:29"，不显示秒）。
- 套用模板弹层每项两级下拉过重：每行一个"个人 / 公共"分段切换，选公共时行内显示负责人选择；顶部提供"全部设为个人 / 全部设为公共"。
- 投票详情：选项的投票人头像应横向堆叠在一行（超过 5 个显示 +N），而不是每人一行。
